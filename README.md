# LLM LangChain Project

A practical project for learning and experimenting with Large Language Models (LLMs), LangChain, Generative AI, prompt engineering, and modern LLM application development using Python.

## 🚀 Overview

This repository contains hands-on implementations and experiments focused on building applications with Large Language Models.

The project covers fundamental concepts of LLM application development and gradually explores more advanced workflows using LangChain and related tools.

## 🧠 Topics Covered

- Large Language Models (LLMs)
- Generative AI
- LangChain
- Prompt Engineering
- Chat Models
- LLM Chains
- Structured Outputs
- Message Handling
- Document Processing
- Embeddings
- Vector Databases
- Retrieval-Augmented Generation (RAG)
- AI Application Development

## 🛠️ Tech Stack

- Python
- LangChain
- OpenAI / LLM APIs
- UV
- Jupyter Notebook
- Python-dotenv
